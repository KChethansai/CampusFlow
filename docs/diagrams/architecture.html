CampusFlow — System Architecture

4-layer: routers → controllers → models + services. Sources: backend/app.js, backend/APIs/index.js, backend/server.js.

Client layer — PWA frontend (React 19 + Vite)

Browser → Vite dev server / Vercel dist → React Router 8 · Zustand cf_auth session · Axios client (src/api/axios.js, refresh interceptor) · Socket.IO client (src/store/useSocket) · Tailwind 4 · PWA via vite-plugin-pwa (frontend/vite.config.js)
⇅ HTTPS / WSS

Server layer — Express 4 (backend/app.js → backend/server.js)

Middleware chain (in order): trust proxy → securityMiddleware (Helmet + global rate-limit) → CORS allowlist (CLIENT_URL) → express.json({limit:'1mb'}) → express-mongo-sanitize → rejectUnsafePayload → credential limiters (10 req/15 min × 6 auth endpoints) → /api/v1 router
23 routers (backend/APIs/index.js):
authusersinstitutionsdepartmentscoursessubjectsroomstimetableenrollmentsassignmentssubmissionsattendanceannouncementseventscompaniesjob-drivesjob-applicationsrequestsnotificationsanalyticssearchstudyai-reports
→ verifyToken(...roles) (middlewares/verifyToken.js, role re-checked from DB) → auditLog → validate (422) → controllers/ (25: auth, user, institution, … + filecontroller.js, placementcontroller.js) → services/ (notification, digest cron, email, ai, eligibility, activityLog, accountProvisioning) → models/ (Mongoose 8, 22 schemas)
Realtime: Socket.IO singleton (config/socket.js: initSocket, rooms user:{id} + institution:{id}) · weekly digest via node-cron (services/digest.service.js 0 6 * * 0) · uploads Multer → local disk / Cloudinary · SMTP via Nodemailer
⇅ Mongoose 8 ODM

Database layer — MongoDB (Atlas prod / local dev)

Users · Institutions · Departments · Courses · Subjects · Rooms · Timetable · Enrollments · Assignments · Submissions · AttendanceSessions · Announcements · Events · Companies · JobDrives · JobApplications · Requests · Notifications · AIReports · LearningResources · RefreshTokens · ActivityLogs

External services

MongoDB Atlas · Cloudinary CDN (prod uploads) · SMTP (password-reset + digest mail, in-app fallback without) · OpenAI gpt-4o-mini (AI reports, snapshot fallback without key)
Health: GET /api/health (unversioned) · errors via notFound + errorHandler. See docs/ops-handover.md for env + release checklist.
