CampusFlow — Overall Request Flow

Sources: backend/app.js, middlewares/verifyToken.js, middlewares/validate.js, middlewares/errorHandler.js, utils/scope.js, src/api/axios.js.

1. Browser (React + Vite)

Axios client reads access token from localStorage cf_auth, sends Authorization: Bearer <15m access> to VITE_API_URL (must end /api/v1). Expired token → interceptor calls POST /auth/refresh silently.

↓ HTTPS

2. Express middleware chain (app.js)

trust proxy → Helmet + global rate-limit → CORS allowlist → 1 MB JSON cap → mongoSanitize → rejectUnsafePayload (400 on $/. keys) → credential limiters (10/15 min) → /api/v1 router.

↓

3. Router → verifyToken(...roles) → validate

Missing/invalid/expired token → 401. Deactivated account or wrong role → 403 (role re-loaded from DB, never JWT claim). Schema violations → 422 with field details.

↓

4. Controller + service + tenant-scoped model

Allowlisted writes only (utils/sanitize.js + pick()); single-object reads via scopedOne(model, req, id) = findOne({_id, institution}) → wrong tenant reads as 404 (no oracle leak). Mongoose errors mapped: CastError → 400, ValidationError → 422, dup key 11000 → 409.

↓

5a. Success → JSON

200 OK / 201 Created (+ pagination {page,limit,total,pages} on lists) rendered by React; realtime side-effects emitted via Socket.IO.

5b. Failure → JSON error

{success:false, message, details?} (+ stack in development). Unknown route → 404 via notFound; file too large → 413.

Status map: 400 invalid ID/payload · 401 auth · 403 forbidden/deactivated · 404 not-found · 409 duplicate · 413 file too large · 422 validation.
